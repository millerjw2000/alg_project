SYNTAX FOR THIS LANGUAGE!

valid operators
---------------------
+
-
*
/
<
>
<=
>=
(
)
==
!=

assignment statement
---------------------
(variable name) = (expression);

conditional statement
---------------------
IF (conditional) THEN
    (statement if true)
ELSE
    (statement if false)
END;

true / false
---------------------
a value of 1 is used to represent true, a value of 0 is used to represent false.

built-in functions
---------------------
avg([args]); ~ Returns the average of a series of arguments.
min([args]); ~ Returns the minimum of a series of arguments.
max([args]); ~ Returns the maximum of a series of arguments.
abs(arg);    ~ Returns the absolute value of an argument.
round(x,y);  ~ Rounds x to y digits.
pow(x,y);    ~ Raises x to the power of y.
sqrt(arg);   ~ Returns the square root of an argument.
